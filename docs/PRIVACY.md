# 聆窗 LingWindow 隐私说明

聆窗是基于 AudioScript 的独立开源衍生项目，感谢原作者与贡献者。本说明描述此版本的行为，不代表上游项目的政策。

## 使用统计与错误报告

此版本不向 Aptabase、Sentry 或其他遥测服务发送使用事件或错误报告。前端不注册用于上报的全局错误监听器，后端遥测接口为空操作。旧配置中的统计开关不能启用收集。

本地诊断日志仍会保存在设备上。用户可主动导出日志；分享前请检查其中可能包含的设备信息、文件路径或诊断上下文。导出不等于上传，本应用不自动上传这些日志。

## 离线处理与网络访问

语音转写与本地模型翻译在设备上执行。首次获取模型、用户主动打开外部网页等功能仍可能使用网络，不能将本应用理解为完全禁止所有网络连接。模型下载服务会获得正常下载请求所需的网络信息。使用系统语音或系统翻译时，所需权限和语言资源由操作系统管理。

## 更新隔离

此版本不使用 AudioScript 的更新端点或签名公钥，也不提供自动下载安装。更新检查和安装接口均明确返回更新渠道不可用，直到聆窗拥有独立且经过验证的签名分发渠道。请仅从聆窗自己的发布页获取后续版本，不要将上游应用更新包当作本项目更新包安装。
